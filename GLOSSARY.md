# WR!TE writing library

WR!TE holds several kinds of writing and the history attached to them.

## Language

**Project**:
A writing work that gathers ordered chapters or scenes and related research Ideas.
_Avoid_: Collection, when referring to a work's reading order

**Chapter / Scene**:
Writing placed in a Project's reading order. The same document can belong to several Projects.
_Avoid_: Copy, when referring to a Project's reference to existing writing

**Develop an Idea**:
Create a linked poem or story from an Idea while keeping the original notes and versions available.
_Avoid_: Replace, when referring to developing an Idea

**Checkpoint**:
A Snapshot with a writer-chosen name marking a meaningful stage of the work.
_Avoid_: Automatic backup, when referring to a named revision

**Document**:
A piece of writing in the library: a poem, story, or idea.
_Avoid_: Poem as a blanket name for all writing

**Idea**:
A document for notes, fragments, research, and writing that is not yet a poem or story.
_Avoid_: Scratchpad, when referring to this document type

**Idea status**:
An early stage in a document's writing process, independent of its document type.
_Avoid_: Idea type, when referring to writing progress

**Trash**:
Deleted writing kept so that the writer can recover it together with its history.
_Avoid_: Permanent deletion, when referring to moving writing to Trash

**Snapshot**:
A saved version of a document that the writer can inspect or restore.
_Avoid_: Backup, when referring to one version of one document

**Library backup**:
An exported copy of the writing library and its associated data.
_Avoid_: Snapshot, when referring to the whole library

**Quiet view**:
The writing workspace with its Project and Tools panels put away. The same manuscript stays open.
_Avoid_: Focus mode, which dims surrounding lines in the editor

**Workspace view**:
The writing workspace with the writer's chosen Project and Tools panels restored.

**Appearance**:
A saved color palette, independent of writing view, layout, and document formatting.
